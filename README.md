# exam-8
поиск дубликатов  файлов
 Опции:
  --scan <path>      сканирование директорий
  --exclude <path> исключение директорий из сканирования
  --level <N>   N - целое значение уровень вложенности каталогов, по умолчанию 0, inf - максимальный уровень воженности
  --min-size <bytes>       минимальный размер файлов для сканирования
  --mask <pattern>         File name mask (can be used multiple times)\n"
  --block-size <bytes>     размер блока данных для таблицы хешей.
  --hash <algorithm>       выбор алгоритма сканирования crc32 или xor. По умолчанию xor.
 --help             справка - при запуске программы без параметров выводится справка и примеры ввода для командной строки.
