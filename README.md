# exam-8
## Поиск дубликатов файлов

**Опции:**

  --scan <path>      сканирование директорий  
  --exclude <path>   исключение директорий из сканирования  
  --level <N>        N - целое значение, уровень вложенности каталогов  
                     (по умолчанию 0, inf - максимальный уровень)  
  --min-size <bytes> минимальный размер файлов для сканирования  
  --mask <pattern>   маска имени файла (можно использовать несколько раз)  
  --block-size <bytes> размер блока данных для таблицы хешей  
  --hash <algorithm> выбор алгоритма: crc32 или xor (по умолчанию xor)  
  --help             справка

> При запуске программы без параметров выводится справка и примеры ввода для командной строки.
